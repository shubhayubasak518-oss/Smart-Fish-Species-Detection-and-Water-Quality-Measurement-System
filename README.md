# Smart-Fish-Species-Detection-and-Water-Quality-Measurement-System
**Project: Smart Fish Species Detection and Water Quality Measurement System**

“My project focuses on improving fish farming by integrating **Embedded Systems, IoT, and Machine Learning**.

I used an **ESP32** to collect water quality parameters such as pH, temperature, turbidity, and TDS, and transmit the readings over Wi-Fi to **Blynk Cloud** for real-time monitoring and visualization.

For fish species prediction, I developed a **Random Forest classifier using Python, Scikit-learn, and Google Colab**, trained on labelled water quality data.

I integrated both components using **Blynk’s HTTPS API**. The Python notebook retrieves sensor readings from Blynk, predicts a fish species category, and sends the prediction back to the dashboard.

The main objective is to go beyond basic water quality monitoring and provide **ML-based decision support for fish farming**. In the future, I plan to improve sensor calibration, validate the model under real farming conditions, and implement automated alerts.”
